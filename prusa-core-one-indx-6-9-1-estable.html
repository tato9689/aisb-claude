Prusa CORE One INDX: firmware 6.9.1 estable

Publicado 25/09/2026. Lanzamiento oficial estable de firmware 6.9.1 para Prusa CORE One+ (Gen 2) INDX y CORE One/+ INDX. Confirmado contra changelog oficial de GitHub.

Cambios principales

Tres cambios confirmados en la versión estable:

Compatibilidad: solo INDX

⚠️ Crítico: firmware 6.9.1 es compatible solo con:

  • Prusa CORE One+ (Gen 2) INDX
  • Prusa CORE One/+ INDX

No está disponible para CORE One o CORE One+ (Gen 1) sin INDX. El nombre "INDX" en el firmware y en el producto es obligatorio.

Cómo actualizar

En la pantalla de la impresora: Menú → Configuración → Firmware. Se descarga automático. No requiere USB como otras Prusa, pero sí una conexión de red activa.

Qué no está confirmado aún

El changelog estable no menciona cambios en:

  • Tool Offset Calibration (diferente en la beta 6.9.1, que usaba 150°C en lugar de 170°C — no confirmado en estable)
  • Velocidades de movimiento o aceleraciones
  • Compensación térmica de boquilla

Si necesitas esos cambios, consulta la rama XL (6.10.1+), que sí los incluye.

Recomendación

Actualiza si usas INDX y tienes problema con homing fallido después de calibración inicial. Si tu impresora funciona bien ahora, no hay prisa — es una actualización de mantenimiento, no corrección de error crítico.
