Prusa XL/XL+: firmware 6.10.2 corrige fallo de extrusor tras cambio manual

Publicado: 16 de septiembre de 2026 · Última revisión: 23/09

Resumen de cambios en 6.10.2

El firmware 6.10.2 está confirmado como versión estable de Prusa para las impresoras XL y XL+. Se lanzó el 16 de septiembre de 2026 y corrige principalmente fallos de comportamiento identificados en la rama anterior, 6.10.1.

Tipo Descripción Modelos afectados Confirmado
Fix Motor extrusor no gira tras cambio manual de herramienta mientras impresora está inactiva XL / XL+ ✓ Changelog oficial GitHub
Fix Pantalla se congela de forma aleatoria (interacción display-WiFi) XL / XL+ ✓ Changelog oficial GitHub
Fix Reanudación de impresión se queda en "Heating..." en impresoras multiherramienta XL / XL+ (multi-tool) ✓ Changelog oficial GitHub
Fix Posición de parking incorrecta en calibración Tool Offset XL (sin +) ✓ Changelog oficial GitHub
Improvement Velocidad de parking de cama aumentada de 5 a 15 mm/s XL / XL+ ✓ Changelog oficial GitHub
Fix Estabilidad mejorada del sensor Tool Offset XL+ (solo) ✓ Changelog oficial GitHub

¿Qué diferencia 6.10.2 del CORE One INDX?

El firmware del CORE One INDX corre en paralelo sobre una rama separada y no hereda cambios de la rama XL automáticamente. Aunque el número de versión sea cercano, el contenido es distinto:

  • 6.10.2 XL/XL+: foco en cambio manual de herramientas, estabilidad de display, multiherramienta.
  • 6.9.1 CORE One INDX (beta): foco en calibración de offset a menor temperatura (150°C vs 170°C), mejora de fiabilidad de probe, acceso durante calibración.

No aplique el firmware de una rama a la otra: Prusa no lo valida y pueden fallar.

Quién debería actualizar

Si tienes… Prioridad Motivo
XL / XL+ con cambios manuales de herramienta frecuentes Alta El fix principal de 6.10.2 afecta exactamente a eso
XL con problemas de posición de parking históricos Alta El fix de calibración Tool Offset es específico
XL/XL+ estable sin los problemas de arriba Media La velocidad de parking no afecta calidad, solo comodidad
XL+ (sin cambios manuales) Baja El fix del sensor Tool Offset es preventivo

Qué no está confirmado aún

Ni el changelog ni los reportes disponibles mencionan:

  • Mejoras en velocidad de impresión o calidad de superficie.
  • Cambios en compensación térmica (eso fue 6.10.1, no 6.10.2).
  • Actualizaciones de calibración de nivelación de cama.

Si necesitas alguno de esos cambios, sigue en 6.10.1.

Cómo actualizar

Prusa XL/XL+ se actualiza desde el menú en pantalla de la impresora: Menú > Configuración > Sistema > Actualización de firmware. Necesitas una unidad USB con la imagen descargada desde help.prusa3d.com/downloads/xl.

Antes de actualizar:

  • Descarga desde el sitio oficial de Prusa, no de terceros.
  • Asegúrate de que la USB está formateada FAT32.
  • No interrumpas la actualización (cero riesgo, pero es lo obvio).
