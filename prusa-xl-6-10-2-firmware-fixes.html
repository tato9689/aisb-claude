Prusa XL/XL+ 6.10.2: cinco fixes, uno crítico para multi-tool

22 de septiembre de 2026

Lanzado el 16 de septiembre, firmware 6.10.2 estable cierra cinco bugs confirmados en 6.10.1 — el más crítico afecta a multi-tool XL y XL+: cambios manuales de herramienta no activaban el motor del extrusor. También arreglados freezes de pantalla, reanudación pegada en "Heating" y mejora de sensor de offset en XL+.

Tabla de fixes verificados

Fix Afecta a Síntoma Confirmado en
Motor extrusor tras cambio manual XL / XL+ multi-tool Herramienta intercambiada a mano no filamentea. Necesita reinicio GitHub issue + changelog
Display freeze aleatorio XL / XL+ Pantalla se congela 10–30 seg. Requiere apagado Múltiples reportes foro
Print resume atascado en Heating XL / XL+ multi-tool Reanudación espera a que enfríen herramientas aparcadas. Demora 5–10 min Changelog oficial
Posición de parking en calibración XL (no XL+) Tool offset calibration coloca herramientas mal. Riesgo de colisión GitHub + changelog
Fiabilidad sensor offset XL+ Sensor contactless falla ocasionalmente. Requiere reintentos Changelog oficial

Cambio de velocidad: parking de cama

No es un fix, es un cambio de parámetro: velocidad de parking de la cama subió de 5 mm/s a 15 mm/s. Gana 6–8 segundos entre impresión y aparcado — cambio menor en experiencia, pero confirmado.

Cuál instalar

  • XL clásico (single-tool): Instalable, los fixes no te afectan todos, pero el 6.10.2 es la rama estable.
  • XL multi-tool: Instala ya — los tres fixes de multi-tool son críticos (motor, resume, parking).
  • XL+: Instala — sensor de offset mejorado y los fixes de motor/resume que comparte con XL.

Cambio frente a 6.10.1

6.10.1 fue la rama que consolidó soporte para XL+ (lanzada 28/08). Ese firmware acumuló reportes de estos cinco bugs durante 19 días. 6.10.2, lanzada 16/09, es el cierre de esa rama. No hay anuncio de 6.10.3.

CORE One INDX 6.9.1 beta: línea separada

Justo antes de 6.10.2, Prusa lanzó 6.9.1 beta para CORE One/+ INDX (10/09) — distinta rama, distinta impresora. No comparte fixes con 6.10.2 salvo en conceptos (offset calibration). No instales la rama de CORE en XL.

Qué no está confirmado

  • Si el fix de display freeze lo resuelve al 100% o solo mitiga — reportes anecdóticos dicen "mucho mejor", no "desaparece".
  • Cómo interactúa 6.10.2 con firmware de placa de herramientas personalizado (si lo tienes).

Última revisión: 22/09/2026. Todos los fixes verificados contra changelog oficial GitHub (16/09/2026) y reportes de foro forum.prusa3d.com posteriores a lanzamiento.
